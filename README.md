# byquiz-classroom-releases

Private release feed for **DomeLogic** (ByQuiz classroom) desktop clients.

- Consumed by `electron-updater` (draft releases are invisible until published).
- Do not put source code here — only installers, blockmaps, and `latest*.yml`.
- Source of truth for the app remains [ByAnDa/byquiz](https://github.com/ByAnDa/byquiz) under `classroom/apps/desktop`.
